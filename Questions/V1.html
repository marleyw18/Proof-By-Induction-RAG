Prove the following statement by induction.

$$\forall n \in \mathbb{N}, \sum_{i=0}^n i = \frac{n(n+1)}{2}.$$

Feel free to use plain text or LaTeX for your proofs. If you choose to use LaTeX, you might find these commands useful:

  • $\frac{a+b}{x+y}$ is written as \frac{a+b}{x+y}
  • $\sum_{i=0}^{k+1}$ is written as \sum_{i=0}^{k+1}
